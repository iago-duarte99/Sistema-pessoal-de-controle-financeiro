MEU CONTROLE FINANCEIRO — VERSÃO MYSQL

A documentação atual está em README.md.

1. Instale as dependências: cd backend e npm ci.
2. Configure backend/.env com o usuário finance_app e a senha local.
3. Revise e execute os scripts auxiliares em backend/sql pelo MySQL Workbench.
4. Execute npm run check:db e npm start no diretório backend.
5. Abra http://localhost:3000 no navegador.

Não abra index.html por duplo clique para usar esta versão.
Os dados antigos de localStorage não foram apagados.
Leia docs/MIGRACAO.md antes de importar os dados do navegador.
Consulte docs/RELATORIO.md para o inventário das alterações e testes.
